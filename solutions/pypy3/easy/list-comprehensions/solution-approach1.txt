# Technique   nested-list-comprehension
# Time        O(x * y * z)
# Space       O(x * y * z)
# Insight     The implementation generates all coordinate triplets within the inclusive bounds [0, x], [0, y], and [0, z] and filters them based on the condition that their sum does not equal n.
# Interview   Before: "I would use three nested loops to iterate through the ranges and append valid coordinates to a list." After: "Using a list comprehension is more idiomatic in Python, achieving the same O(x * y * z) time complexity while concisely filtering the search space defined by the inclusive cuboid dimensions."
# Pitfalls    (1) Using range(x) instead of range(x + 1) fails to include the upper bound dimension as required by the problem statement.  (2) Forgetting to filter the sum condition results in including coordinates that violate the n constraint.
# ──────────────────────────────────────────────────

def all_possible_coordinates(x, y, z, n):
    return [[i, j, k] 
            for i in range(x + 1) 
            for j in range(y + 1) 
            for k in range(z + 1) 
            if (i + j + k) != n]

if __name__ == '__main__':
    x = int(input())
    y = int(input())
    z = int(input())
    n = int(input())
    print(f"{all_possible_coordinates(x, y, z, n)}")
